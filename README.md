# Libation Station — revitalizovaná verze v2

Statický HTML/CSS/JS web. V této verzi jsou zachované původní barvy i charakter projektu, ale web je technicky a vizuálně vyčištěný.

## Co je upravené
- původní plynule posouvající se fotogalerie, pouze s optimalizovanými WebP fotkami,
- odstraněné pomocné popisky a zbytečné štítky,
- přeformulované hlavní nadpisy a texty,
- výraznější sekce rezervace, menu a kontakt,
- doladěná responzivita pro desktop, tablet i malé mobily,
- WebP obrázky, lazy loading a optimalizace velikosti,
- semantické HTML, přístupnost, focus stavy,
- SEO metadata, canonical, Open Graph, JSON-LD, robots.txt a sitemap.xml.

- Do hlavičky a patičky bylo doplněno nové logo Libation Station (ikona + wordmark).
- Favicon byl nahrazen ikonou LS.
